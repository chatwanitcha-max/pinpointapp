สรุปข้อมูลลับที่ต้องเก็บรักษา (Pinpoint)

เอกสารนี้ระบุว่าอะไรคือ “ข้อมูลลับ” และอะไรไม่ลับ เพื่อเก็บรักษาอย่างถูกต้อง

ข้อมูลที่ต้องเก็บเป็นความลับ (ห้ามแชร์สาธารณะ)

  • รหัสผ่าน/OTP/Recovery codes ของทุกบัญชี (Google, Facebook/Meta, LINE, Vercel, Supabase, Resend ฯลฯ)
  • คีย์/โทเค็นลับทั้งหมด เช่น:
    • META_ACCESS_TOKEN
    • supabase_service_role_key
    • RESEND_API_KEY
    • LINE_CHANNEL_ACCESS_TOKEN
    • LINE_CHANNEL_SECRET
    • GA4_API_SECRET
    • CRM/OpenClaw Webhook Token หรือ Client Secret ต่างๆ
  • ข้อมูลชำระเงิน (บัตร/Wallet/บัญชีธนาคาร/ใบกำกับภาษี)
  • ข้อมูลส่วนบุคคลลูกค้า/พนักงาน (เบอร์โทร อีเมล ที่อยู่ เลขบัตร ปริมาณรายได้ ฯลฯ)

ข้อมูลที่ไม่ลับ (แชร์ได้อย่างระมัดระวัง)

  • META_PIXEL_ID
  • GA4 Measurement ID (G-...)
  • Google Ads ID (AW-...)
  • โดเมน/เว็บไซต์สาธารณะของธุรกิจ

คำแนะนำการเก็บรักษา

  • เก็บ Secrets ไว้ใน Environment Variables เท่านั้น (Vercel/Supabase/Server)
  • ห้ามใส่คีย์ลับในไฟล์ที่ส่งต่อหรืออัปโหลดสาธารณะ
  • กำหนดสิทธิ์ผู้ใช้งานเท่าที่จำเป็น
  • หมุนคีย์ใหม่ทันทีหากคีย์รั่วไหล
