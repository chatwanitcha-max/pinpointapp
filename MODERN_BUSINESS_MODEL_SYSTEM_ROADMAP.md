# Modern Business Model System Roadmap

Prepared: 2026-03-16
Baseline tag: `backup-version-1`

## Goal

Upgrade the current Pinpoint website from a premium brochure site into a full business operating system that:

1. attracts qualified leads
2. qualifies and routes them automatically
3. supports consultation and onboarding
4. helps deliver accounting and compliance services consistently
5. improves SEO, AI discoverability, and conversion over time

## System pillars

### 1. Growth engine

- high-conversion landing pages
- SEO topic clusters
- lead capture and scoring
- ad tracking and attribution
- consultation booking flow

### 2. Trust engine

- stronger proof sections
- structured FAQ and service scope
- source-backed articles
- client process transparency
- bilingual Thai / English content quality

### 3. Operations engine

- service runbooks
- client intake checklists
- document collection workflow
- recurring status updates
- internal case tracking

### 4. Automation engine

- LINE OA intake
- CRM sync
- OpenClaw orchestration
- analytics reporting
- content publishing workflow

## Full-option target state

### Public website

- homepage with strong offer, segments, proof, and CTA
- service pages per category and per subservice
- blog clusters by search intent
- FAQ and resources linked to conversion paths
- multilingual content with consistent terminology

### Lead system

- website form
- LINE OA intake
- auto lead scoring
- routing by service, urgency, and language
- CRM pipeline or Airtable view
- follow-up templates

### Service delivery system

- onboarding checklist by service type
- DBD / visa / permit document packs
- accounting monthly checklist
- customer updates and response templates
- issue triage and escalation logic

### AI and search system

- stronger structured data
- llms.txt and sitemap strategy
- content calendar by service cluster
- competitor and keyword tracking
- AI-assisted content briefs and publishing

## Recommended implementation order

### Phase 1: Foundation

- clean git repo and baseline release
- finalize env and integration readiness
- finalize brand voice and terminology
- create modular content/data structure for services and FAQ

### Phase 2: Conversion

- redesign homepage for clearer segmentation
- build dedicated service landing pages
- improve lead form and thank-you experience
- connect LINE OA + CRM + follow-up logic

### Phase 3: Content and SEO

- create service clusters and article clusters
- add more internal linking and schema
- build topic calendar for 30-60 high-intent pages
- add competitor-informed SEO workflow

### Phase 4: Client operations

- build client onboarding workflow
- create reusable service checklists
- create case update templates
- connect OpenClaw workflows for intake, support, and follow-up

### Phase 5: Dashboard and reporting

- conversion dashboard
- lead source reporting
- service request tracking
- content performance review

## What to build next in this repo

1. reusable data files for services, FAQ, and proof blocks
2. modular page rendering for service landing pages
3. lead pipeline view or CRM-ready export
4. OpenClaw workflow prompts for lead qualification and client response
5. SEO page generator for service-specific clusters

## Success criteria

- more consultation leads
- faster reply time
- clearer service understanding for prospects
- lower manual follow-up burden
- better organic visibility for accounting and compliance searches
- better readiness for Thai and foreign clients
