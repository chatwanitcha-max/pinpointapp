# Outbound Contact Playbook

คู่มือนี้ออกแบบมาเพื่อให้ Pinpoint ติดต่อผู้สนใจบริการแบบสุภาพ ให้ข้อมูลตรงกับสิ่งที่ลูกค้ากำลังหา และไม่ทำให้รู้สึกว่าถูกเร่งขายหรือถูกรบกวน

## 1. Minimum outbound credentials

### A. Email outbound

ต้องมีใน `D:\PINPOINT\WEBAPP\.env.local.txt`

- `RESEND_API_KEY`
- `LEAD_FROM_EMAIL`
- `LEAD_TO_EMAIL`

สิ่งที่คุณต้องทำ

1. สมัครหรือ login ที่ `https://resend.com/api-keys`
2. เพิ่ม domain หรือ subdomain สำหรับส่งอีเมล เช่น `mail.pinpointaccountingservice.com`
3. ตั้งค่า DNS ตามที่ Resend ให้เพื่อ verify domain
4. สร้าง API key
5. ใส่ค่า 3 ตัวข้างต้นลง env

หมายเหตุ

- `LEAD_FROM_EMAIL` ควรเป็นอีเมลในโดเมนที่ verify แล้ว เช่น `contact@pinpointaccountingservice.com`
- `LEAD_TO_EMAIL` คืออีเมลที่ทีมต้องการรับลีดเข้า เช่น `pinpoint.la@gmail.com`

### B. LINE OA outbound

ต้องมีใน `D:\PINPOINT\WEBAPP\.env.local.txt`

- `LINE_CHANNEL_ACCESS_TOKEN`
- `LINE_CHANNEL_SECRET`
- `LINE_TARGET_ID`
- `LINE_AUTO_REPLY_TEXT`

สิ่งที่คุณต้องทำ

1. Login ที่ `https://developers.line.biz/console/`
2. เปิด Messaging API channel ของ LINE OA
3. คัดลอก Channel access token และ Channel secret
4. ตั้ง webhook URL เป็น `https://pinpointaccountingservice.com/api/line-webhook`
5. เปิด `Use webhook`
6. หา `LINE_TARGET_ID` ของห้องหรือผู้รับที่ต้องการให้ระบบแจ้งลีดเข้า

หมายเหตุสำคัญ

- ข้อความแบบ reply ใช้กับคนที่ทักเข้ามาหรือ add OA แล้ว
- ข้อความแบบ push ต้องใช้กับผู้รับที่ระบบส่งได้ตามสิทธิ์ของ LINE OA
- อย่าใช้ LINE OA แบบหว่านข้อความหาคนที่ไม่เคยมีความสัมพันธ์กับบัญชีมาก่อน

### C. Tracking and attribution

ต้องมีเพิ่มเมื่อพร้อมวัดผลจริง

- `GA4_MEASUREMENT_ID`
- `GA4_API_SECRET`
- `META_PIXEL_ID`
- `META_ACCESS_TOKEN`

## 2. What we should automate first

ลำดับที่คุ้มที่สุดสำหรับธุรกิจคุณ

1. Inbound first reply
2. Lead alert เข้าอีเมลหรือ LINE
3. Follow-up 1 ครั้งสำหรับคนที่เคยติดต่อแล้ว
4. Summary ส่งเข้าฐานข้อมูลหรือ CRM
5. Daily reminder ให้ทีมโทรกลับ

ไม่ควรเริ่มจาก cold blast หรือยิงหาลูกค้าจำนวนมากทันที

## 3. Safe contact policy

### ติดต่อได้

- คนที่กรอกฟอร์มบนเว็บ
- คนที่ทัก LINE OA เข้ามา
- คนที่โทรเข้ามาแล้วขอให้ติดต่อกลับ
- บริษัทที่เปิดข้อมูลติดต่อไว้บนเว็บไซต์ทางการในเชิงธุรกิจ และเราอ้างอิงเรื่องที่เกี่ยวข้องกับบริการได้จริง

### ไม่ควรทำ

- ดึงเบอร์หรืออีเมลส่วนตัวจาก social profile แล้วทักขายตรง
- ส่งข้อความเหมือนกันจำนวนมากโดยไม่ดูบริบท
- ตามหลายรอบเกินไปถ้าลูกค้าไม่ตอบ
- ใช้ภาษากดดัน เช่น รีบตัดสินใจวันนี้เท่านั้น หรือทักซ้ำติดๆ กัน

### Frequency ที่แนะนำ

- First touch 1 ครั้ง
- Follow-up อีก 1 ครั้งหลัง 3-5 วัน
- ถ้ายังไม่ตอบ ให้ปิดรอบและรอให้ลูกค้ากลับมาเอง

## 4. Messaging principles

ทุกข้อความควรมี 4 ส่วน

1. เหตุผลที่ติดต่ออย่างโปร่งใส
2. อ้างอิงสิ่งที่ลูกค้าน่าจะกำลังหาอยู่
3. ให้ข้อมูลที่มีประโยชน์ก่อนเสนอขาย
4. ปิดด้วย next step ที่เบาและไม่กดดัน

## 5. Recommended structure for first outreach

- Checklist งานบัญชีและภาษีที่ธุรกิจมักเริ่มตามเมื่อเอกสารเริ่มเยอะขึ้น
- ข้อมูลสำหรับบริษัทที่ต้องการจัดระบบบัญชีและภาษีให้ชัดขึ้น

### Version B: reply after inbound lead

สวัสดีค่ะ ขอบคุณที่ติดต่อ Pinpoint Accounting & Service นะคะ

รบกวนแจ้งได้เลยค่ะว่าตอนนี้ต้องการให้ทีมช่วยเรื่องอะไรเป็นหลัก เช่น บัญชีและภาษีรายเดือน จดทะเบียนบริษัท เปลี่ยนแปลงข้อมูล DBD วีซ่า Work Permit หรือใบอนุญาตธุรกิจ

### Version C: polite follow-up

สวัสดีค่ะ ขออนุญาต follow up ข้อความก่อนหน้านี้นะคะ

หากยังไม่สะดวกตอนนี้ ไม่เป็นไรเลยค่ะ ไว้ติดต่อกลับมาเมื่อพร้อมได้เสมอนะคะ

## 6. Segment-based openers

### ธุรกิจเปิดใหม่

หากกำลังเริ่มจัดตั้งบริษัทหรือเพิ่งเริ่มดำเนินงาน ทีมช่วยดูให้ได้ค่ะว่าควรเริ่มจากงานจดทะเบียน ภาษี และระบบเอกสารส่วนไหนก่อน เพื่อให้เริ่มธุรกิจได้เป็นระเบียบมากขึ้น

### ธุรกิจที่เอกสารเริ่มเยอะ

ถ้าช่วงนี้เอกสารขาย ซื้อ ธนาคาร หรือภาษีเริ่มมีจำนวนมากขึ้น ทีมช่วยจัดระบบและวางรอบส่งงานให้ได้ค่ะ เพื่อให้การยื่นภาษีและงานบัญชีราบรื่นขึ้น

### บริษัทต่างชาติหรือมีต่างชาติร่วมบริหาร

หากมีกรรมการ ผู้ถือหุ้น หรือพนักงานต่างชาติ ทีมช่วยดูให้ได้ทั้งเรื่องจดทะเบียนบริษัท วีซ่า Work Permit และเอกสารที่เกี่ยวข้องกับหน่วยงานต่าง ๆ ค่ะ

## 7. Soft CTA examples

ใช้ CTA เบา ๆ เท่านั้น

- หากสะดวก ส่งข้อมูลคร่าว ๆ มาได้เลยค่ะ
- หากต้องการ ทีมช่วยสรุป checklist เบื้องต้นให้ได้ค่ะ
- ถ้าต้องการคุยเร็ว สามารถโทรหรือทัก LINE OA ได้เลยค่ะ
- หากยังไม่สะดวกในตอนนี้ สามารถเก็บข้อมูลนี้ไว้ก่อนและติดต่อกลับมาเมื่อพร้อมได้ค่ะ

## 8. Opt-out style

ทุกข้อความเชิง outreach ควรมีทางลงแบบสุภาพ

- หากไม่สะดวกในช่วงนี้ สามารถละข้อความนี้ได้เลยนะคะ
- หากไม่ต้องการรับข้อมูลลักษณะนี้เพิ่มเติม แจ้งทีมได้เลยค่ะ
- หากตอนนี้ยังไม่ใช่เรื่องเร่งด่วน ไว้ติดต่อกลับมาเมื่อพร้อมได้เสมอค่ะ

## 9. Channel-specific rules

### Email

- ใช้หัวข้ออีเมลแบบให้ข้อมูล ไม่ใช้ clickbait
- ส่งจากโดเมนบริษัทที่ verify แล้ว
- ถ้าเป็นข้อความเชิง nurture ควรมีทาง opt-out
- อย่าส่งถึงคนเดิมถ้ายังไม่ตอบเกิน 2 ครั้งในรอบเดียว

### LINE OA

- ใช้กับคนที่ add friend หรือมี interaction กับ OA แล้วเป็นหลัก
- ตอบเร็วและสั้นก่อน แล้วค่อยเก็บรายละเอียด
- อย่าส่ง push message ที่ยาวเกินความจำเป็น

### Phone

- ใช้เมื่อ lead ขอให้โทรกลับ หรือทิ้งเบอร์ไว้ชัดเจน
- เปิดสายด้วยการขออนุญาตคุยเสมอ
- ถ้าอีกฝ่ายไม่สะดวก ให้เสนอส่ง checklist ทาง LINE หรืออีเมลแทน

## 10. What success looks like

เป้าหมายของ outbound ที่ดีไม่ใช่การปิดขายทันที แต่คือ

- ลูกค้ารู้สึกว่าเราเข้าใจปัญหาเขา
- ลูกค้าอ่านแล้วไม่รู้สึกว่าถูกขายรุกหนัก
- ลูกค้ายอมตอบกลับหรือส่งข้อมูลเบื้องต้น
- ทีมได้ข้อมูลมากพอจะประเมินเคสและนัดคุยต่อ
