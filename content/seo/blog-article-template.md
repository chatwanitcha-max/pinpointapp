# SEO Blog Template (Team-Ready)

Use this template to publish consistent, high-quality articles that rank on Google and are easy for AI search to summarize.

## 1) Metadata (Before writing)
- Primary keyword:
- Secondary keywords (3-6):
- Search intent: Informational / Comparison / Checklist / How-to
- Target money page to link: (choose 1)
- Local intent page to link: (choose 1)
- 1 related article to link:
- References (official sources preferred):

## 2) Title + Summary
H1 (60-70 chars TH / 50-60 chars EN):

TL;DR (2-3 bullet points):
- ...
- ...
- ...

## 3) Body Structure
H2: Why this matters (business outcome)
- Explain the business risk/cost if ignored

H2: Requirements / checklist
- Use numbered checklist

H2: Step-by-step (simple workflow)
1. ...
2. ...
3. ...

H2: Common mistakes (and how to avoid)
- Mistake -> Fix

H2: When to ask for help
- Clear criteria (time, complexity, risk)

## 4) Internal Links (Required)
Add a short "Related services" box:
- Link to 1 money page (service page)
- Link to 1 local page (Bangkok intent)
- Link to 1 related blog post

## 5) FAQ (AEO)
Add 3-5 FAQs at the end (question style, short answers).

Example:
Q: ต้องเตรียมเอกสารอะไรบ้าง
A: ...

## 6) References (E-E-A-T)
List 3-8 source links (official sites preferred).
Add a note: "Always verify latest requirements with official authorities."

## 7) Publish Checklist
- Title + meta description fit length
- 1 H1 only
- At least 2 internal links
- At least 1 FAQ section
- No index-blocking meta tags
- Run `node scripts/generate-blog.mjs` before deploy (updates sitemap/feed if applicable)
